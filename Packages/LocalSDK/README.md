# XREAL SDK package setup

This project depends on two XREAL Unity package archives that are not included in this repository.

1. Download `com.xreal.xr.tar.gz` and `com.xreal.xr.experimental.tar.gz` from [XREAL's official developer portal](https://developer.xreal.com/download/).
2. Review and accept XREAL's applicable API terms yourself.
3. Place both archives in this folder with the exact filenames shown above.
4. Reopen the project in Unity so Package Manager can resolve the local dependencies.

The `.gitignore` excludes the archives. Do not commit or redistribute them unless XREAL's terms explicitly allow it.
